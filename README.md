# VOX – Android Edition

VOX is a voice-enabled productivity system designed to make task management measurable, structured, and time-bound.

The Android edition of VOX is built using **Kotlin** and **Firebase**, focusing on smart productivity tracking and seamless device interaction.

---

## 🚀 Features

- **Google Sign-In** authentication
- **Custom username & avatar selection**
- **Unique 6-character pairing code** for cross-device connection
- **Voice-powered task creation**
- **24-hour expiry task model**
- **Focus Index tracking**
- **Real-time weather and time display**
- **Reminders with notifications**
- **Cloud clipboard with secure sync model**

---

## 📊 Productivity Logic

VOX introduces a measurable productivity system.

- Every task has a **24-hour lifecycle**
- Completed tasks are marked **Done**
- Incomplete tasks become **Missed**

**Focus Index**

This creates a simple metric to track daily productivity consistency.

---

## 🛠 Tech Stack

- **Language:** Kotlin
- **Authentication:** Google Sign-In
- **Backend:** Firebase Realtime Database
- **Cloud Sync:** Firebase
- **Platform:** Android

---

## 📱 Purpose

VOX aims to transform task management from simple lists into a **measurable productivity system**, helping users understand their work patterns and consistency.
